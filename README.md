## Sobre o Projeto

O **SyntaxWear** é um site fictício de e-commerce focado na venda de tênis e sneakers, com visual moderno, responsivo e navegação intuitiva. O projeto foi desenvolvido para fins de estudo e portfólio, utilizando apenas HTML e CSS.

---

## Estrutura de Pastas

```
├── index.html                # Página principal do site
├── README.md                 # Documentação do projeto
├── css/                      # Estilos gerais e componentes
│   ├── base.css              # Estilos base do site
│   ├── reset.css             # Reset de estilos
│   ├── variables.css         # Variáveis CSS (fontes, cores)
│   └── components/           # Estilos de componentes
│       ├── header.css        # Cabeçalho e navegação
│       ├── hero.css          # Seção principal (hero)
│       ├── product-category.css # Categorias de produtos
│       ├── product-grid.css  # Grid de produtos
│       └── footer.css        # Rodapé
├── images/                   # Imagens do site
│   ├── banners/              # Banners principais
│   ├── favicons/             # Favicons do site
│   ├── icons/                # Ícones SVG (menu, redes sociais, etc)
│   ├── logo/                 # Logo da marca
│   └── products/             # Imagens dos produtos
├── js/                       # (Reservado para scripts JS futuros)
```

---

## Tecnologias Utilizadas

- **HTML5**
- **CSS3** (com organização modular por componentes)
- **Google Fonts** (Ubuntu)
- **Imagens SVG e JPG**

---

## Funcionalidades e Seções

- **Header:** Navegação principal, logo, menu mobile e links rápidos.
- **Hero:** Destaque de produto com chamada para ação.
- **Categorias:** Cards para navegação entre estilos de tênis (Casual, Esporte, Moderno, Futurista).
- **Grid de Produtos:** Destaques visuais de produtos e estilos.
- **Footer:** Newsletter, redes sociais e navegação adicional.

---

## Como Visualizar o Projeto

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em seu navegador.
3. Navegue pelas seções e explore o layout responsivo.
